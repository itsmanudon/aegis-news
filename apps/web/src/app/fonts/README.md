# Pinned local typefaces

These are unmodified WOFF2 binaries from the official font maintainers. They are
self-hosted with `next/font/local`; neither builds nor browsers fetch remote fonts.
Full upstream character coverage is retained. No third-party font CDN or subsetting
service is used. The TrueType-outline Source Serif binaries avoid the upstream
release's noted Windows CFF2 issue. The accompanying licenses are unchanged.
